# American Corner Mtaani — Free AI LMS

Flutter + Firebase learning platform. All learner courses are **free**.

## Project architecture
- Flutter mobile/web UI with U.S. flag and KNLS-inspired palette
- Firebase Authentication, Cloud Firestore and Cloud Functions
- Learner course catalog, enrollment and lesson progress
- Instructor and administrator features
- Server-graded quizzes and verifiable certificates
- AI tutor grounded in instructor-approved published lesson text

## Development status
This repository is being initialized from the American Corner Mtaani AI LMS v2 starter. It is **not production-ready** and requires Firebase configuration, compilation, testing, and approved content. No credentials are committed. Embassy and institutional marks require authorization for public deployment.

## Quick start
Install Flutter and Firebase CLI, generate target platforms with `flutter create --platforms=android,ios,web .`, run `flutter pub get`, then `flutterfire configure`. Configure Firebase auth, Firestore, Cloud Functions and approved content before deployment.
